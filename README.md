# hinder
Hinder is a responsive halal matchmaking and courtship web app modeled on Tinder for Muslims to 'Find Your Hoor.' Hosted on Netlify and backed by NeonDB Serverless Postgres, it offers swipe physics, Super Noor stars, Tawbah rewinds, Wali-chaperoned chat, Sunnah Rizz icebreakers, Mehr filters, voice intros, and a custom flame-crescent badge.
